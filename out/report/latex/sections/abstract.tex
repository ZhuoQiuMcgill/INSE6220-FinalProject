This study presents a statistical quality assessment of Kepler Objects of Interest (KOIs) by classifying them into low- and high-quality categories based on their disposition scores. Using a dataset of 7,994 KOIs from the NASA Exoplanet Archive, we construct a binary classification task yielding 7,211 labeled examples (3,753 low quality, 3,458 high quality) after thresholding. We apply logarithmic and linear transformations to 12 astrophysical and observational features to address skewness and varying scales. Principal Component Analysis (PCA) is employed for dimensionality reduction; the first three principal components capture approximately 73\% of the variance, while retaining four components explains over 80\%. We benchmark multiple machine learning classifiers—including Logistic Regression, Random Forest, and Multilayer Perceptron (MLP)—on both the original 12-dimensional feature set and the PCA-reduced space. Our results demonstrate that while PCA provides a compact representation of the data structure, it results in a loss of predictive power compared to the full feature set. The best performance is achieved by an MLP classifier trained on the original features, attaining a test accuracy of 89.26\% and an F1-score of 0.8898. These findings suggest that a nonlinear model using catalog-level parameters can effectively approximate the complex vetting decisions of the Kepler pipeline.
