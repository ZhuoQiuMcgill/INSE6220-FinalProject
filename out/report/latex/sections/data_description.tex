\subsection{Dataset Overview}
We utilize the Kepler Objects of Interest (KOI) cumulative table from the NASA Exoplanet Archive. The dataset initially comprises 7,994 KOIs. Our analysis focuses on 12 key astrophysical and observational features: orbital period (\texttt{koi\_period}), transit duration (\texttt{koi\_duration}), planetary radius (\texttt{koi\_prad}), equilibrium temperature (\texttt{koi\_teq}), insolation flux (\texttt{koi\_insol}), stellar radius (\texttt{koi\_srad}), transit depth (\texttt{koi\_depth}), model signal-to-noise ratio (\texttt{koi\_model\_snr}), impact parameter (\texttt{koi\_impact}), stellar effective temperature (\texttt{koi\_steff}), stellar surface gravity (\texttt{koi\_slogg}), and Kepler magnitude (\texttt{koi\_kepmag}).

The target variable is the continuous \texttt{koi\_score}. To formulate a binary classification problem, we threshold this score to separate clear false positives from likely candidates. We define ``Low Quality'' (class 0) as samples with \texttt{koi\_score} $< 0.3$ and ``High Quality'' (class 1) as samples with \texttt{koi\_score} $> 0.7$, discarding ambiguous samples in between. This process removes 783 ambiguous samples ($\approx 9.8\%$ of the original data), yielding a final labeled dataset of 7,211 samples (3,753 class 0, 3,458 class 1). This strict thresholding ensures that our models are trained on high-confidence labels, minimizing noise in the ground truth.

\subsection{Feature Transformations}
Many exoplanet features follow power-law distributions or span several orders of magnitude. To improve the performance of linear models and PCA, we apply the following transformations:
\begin{itemize}
    \item \textbf{Log$_{10}$:} Applied to \texttt{koi\_period}, \texttt{koi\_duration}, \texttt{koi\_prad}, \texttt{koi\_teq}, \texttt{koi\_insol}, \texttt{koi\_srad}.
    \item \textbf{Log$_{10}(1+x)$:} Applied to \texttt{koi\_depth} and \texttt{koi\_model\_snr} to handle zero-bounded values with wide dynamic ranges.
    \item \textbf{No Transformation:} Applied to \texttt{koi\_impact}, \texttt{koi\_steff}, \texttt{koi\_slogg}, \texttt{koi\_kepmag}.
\end{itemize}

\subsection{Correlation Analysis}
The transformed features exhibit significant correlations, as shown in Figure \ref{fig:corr_matrix}. For example, planetary radius (\texttt{koi\_prad}) is strongly correlated with transit depth (\texttt{koi\_depth}) and signal-to-noise ratio (\texttt{koi\_model\_snr}). Similarly, stellar parameters like radius and surface gravity show expected physical correlations. These redundancies support the use of PCA to reduce dimensionality while preserving information.
