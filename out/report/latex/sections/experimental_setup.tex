\subsection{Preprocessing Pipeline}
The data preprocessing and modeling pipeline is implemented in Python using \texttt{scikit-learn} \cite{scikit-learn} and \texttt{PyCaret} \cite{pycaret}. The dataset is split into a training set (80\%) and a held-out test set (20\%) using stratified sampling to maintain class balance.
\begin{enumerate}
    \item \textbf{Standardization:} All continuous features are scaled to have zero mean and unit variance. The scaler is fit only on the training data and then applied to the test data to prevent data leakage.
    \item \textbf{PCA Projection:} The PCA transformation is learned from the standardized training data. We retain the first 4 principal components, which explain over 80\% of the total variance.
\end{enumerate}

\subsection{Cross-Validation and Hyperparameter Tuning}
We employ 10-fold cross-validation on the training set to evaluate model stability and tune hyperparameters.
\begin{itemize}
    \item \textbf{Logistic Regression:} We tune the regularization strength ($C$) and penalty type (L1 vs. L2).
    \item \textbf{Random Forest:} We optimize the number of trees (n\_estimators), maximum depth, and minimum samples per split to balance bias and variance.
    \item \textbf{MLP Classifier:} We explore architectures with 1 to 3 hidden layers, varying the number of neurons (e.g., 50-100), activation functions (ReLU, Tanh), and the $\alpha$ parameter for L2 regularization.
\end{itemize}

\subsection{Model Selection Protocol}
Our experimental protocol consists of two phases:
\begin{enumerate}
    \item \textbf{Broad Screening:} We initially compare over 10 different classifiers (including Gradient Boosting, SVM, KNN, etc.) using default hyperparameters to identify top performers on the original 12-dimensional feature set.
    \item \textbf{Focused Analysis:} Based on the screening results and the need for interpretability vs. performance trade-offs, we select Logistic Regression (baseline), Random Forest (ensemble/interpretable), and MLP (high capacity) for in-depth analysis. We evaluate these three models on both the original features and the 4-component PCA space using the held-out test set.
\end{enumerate}
