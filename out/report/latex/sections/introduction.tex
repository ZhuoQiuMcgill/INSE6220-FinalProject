The NASA Kepler mission revolutionized exoplanetary science by monitoring over 150,000 stars to detect periodic dips in brightness caused by transiting planets \cite{borucki2010kepler}. This effort produced thousands of Kepler Objects of Interest (KOIs)—signals that resemble planetary transits but require rigorous vetting to distinguish genuine candidates from false positives, such as eclipsing binaries or instrumental artifacts \cite{batalha2014kepler, coughlin2016dr24}. To automate this process, the Kepler team developed the Robovetter, which assigns a disposition score ($\texttt{koi\_score}$) to each KOI. Ranging from 0 to 1, this score represents the confidence that a signal is a planet candidate \cite{thompson2018dr25, nasa_koi_docs, nasa_koi_score_doc}.

While $\texttt{koi\_score}$ is a critical metric for statistical studies, its calculation relies on complex, computationally intensive pipelines involving simulated transit injections. This raises a practical question: can we effectively assess the quality of a KOI using only the standard catalog-level astrophysical and observational parameters? In this work, we explicitly treat this as a \textit{surrogate modeling} problem: we model extreme $\texttt{koi\_score}$ cases to approximate Robovetter scoring behavior, rather than predicting confirmed planet truth. We aim to automatically classify KOIs into ``low quality'' (likely false positives) and ``high quality'' (likely candidates) categories using a set of 12 derived features, such as orbital period, transit depth, and signal-to-noise ratio.

This classification task presents several challenges. The feature space is high-dimensional and contains variables that span multiple orders of magnitude (e.g., planetary radius vs. orbital period). Furthermore, many features are physically correlated; for instance, transit depth is intrinsically linked to planetary radius and stellar size. These correlations suggest that the effective dimensionality of the problem may be lower than the number of features, motivating the use of dimensionality reduction techniques.

Our specific contributions are as follows:
\begin{itemize}
    \item We construct a clean, balanced binary classification dataset from the continuous $\texttt{koi\_score}$ by applying strict thresholds to identify high-confidence examples.
    \item We perform a detailed exploratory data analysis and apply Principal Component Analysis (PCA) to 12 transformed features, demonstrating that a small set of orthogonal components captures the majority of the variance and reveals underlying physical relationships.
    \item We benchmark a diverse set of machine learning classifiers using an automated screening workflow, and select the top-performing models (LightGBM, Gradient Boosting, Random Forest, Extra Trees, and KNN) for final evaluation on both the original feature space and the PCA-reduced space.
    \item We provide an in-depth analysis centered on the best-performing model (LightGBM) and an interpretable comparator (Random Forest), including ROC analysis, confusion matrices, and feature importance, to interpret how astrophysical parameters drive automated KOI quality assessment.
\end{itemize}
